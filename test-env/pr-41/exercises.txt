# Rep Counter -- Exercise Data
#
# Edit this file to add, remove, or change exercises. No coding needed --
# just keep the "Field: value" shape below. Lines starting with # are
# comments and are ignored. Save the file and refresh the app to see your
# changes (the app also picks this up automatically the next time you're
# online, even after Add to Home Screen).
#
# One exercise per block, separated by a blank line. Fields can be in any
# order; you can leave optional fields blank.
#
# Required fields:
#   Slug        A short unique id: lowercase letters, numbers, and
#               hyphens only, no spaces (e.g. hip-abduction). The app
#               uses this to remember your sets/reps and "last done"
#               history for this exercise -- once you've used an
#               exercise, try not to change its Slug, or that history
#               starts over. If you leave Slug blank, the app makes one
#               up from Name, which is fine for a brand new exercise.
#   Name        The exercise name shown in the app.
#   Category    A short label to group exercises for filtering, e.g.
#               hip, core, back-shoulder, arms, balance-legs. You can
#               invent a new one just by typing it here -- a filter chip
#               for it appears automatically.
#   Equipment   band, dumbbell, or bodyweight (also just a label -- a
#               new one you invent gets its own filter chip too).
#   Sets / Reps / Seconds / Rest
#               Starting numbers (Seconds = per rep, Rest = seconds
#               between sets). These are just the defaults shown when
#               you first open the exercise -- you can always change
#               them per-exercise right in the app too.
#   Description One sentence: what this exercise is for.
#   Setup       How to get into position.
#   Movement    How to do one rep.
#   Tip         A coaching cue or common mistake to avoid.
#
# Optional fields:
#   Tags        Comma-separated labels for cross-cutting things that don't
#               fit Category or Equipment - unlike those two, an exercise
#               can have more than one tag, and each shows up in its own
#               row of filter chips. This file uses two: "hip-flexor"
#               (marks exercises that involve active hip flexion - if a
#               flare-up is present, skip an exercise that actually
#               aggravates it rather than pushing through the pain; these
#               exercises aren't automatically off-limits when the hip
#               flexor is well) and "band-optional" (marks band exercises
#               that still work fine as bodyweight-only, e.g. away from
#               home with no equipment). Typing a new tag here gets it
#               its own filter chip too, same as Category/Equipment.
#               Give a tag an icon by adding a colon and an emoji right
#               after it, e.g. "hip-flexor:⚠️" - that icon then shows up
#               on the filter chip, on every card with that tag, and on
#               the detail page. You only need to write the icon once,
#               on any one exercise that uses the tag (every exercise
#               below repeats it for clarity, but that's not required) -
#               everywhere else the tag is used, just the plain tag name
#               is enough. A tag with no icon anywhere just shows its
#               name with no icon, same as Category/Equipment.
#   StartImage / FinishImage
#               Filename of a photo in the images/ folder, named after
#               this exercise's Slug so it's easy to tell which photo
#               belongs to which exercise - e.g. for Slug: bridge,
#               images/bridge.jpeg. Leave both blank to use a built-in
#               line-drawing icon instead. Two common ways to fill
#               these in:
#               - One photo per position: name them images/<slug>-start.jpeg
#                 and images/<slug>-finish.jpeg - they're shown side by side.
#               - One combined photo: if you already have a single
#                 photo showing both the start and finish position
#                 (e.g. a "before/after" side-by-side shot), just name
#                 it images/<slug>.jpeg and put that in StartImage,
#                 leaving FinishImage blank - it's shown at full size
#                 instead of being cropped in half.
#
# Exercise order matters: when you check off several exercises and tap
# "Run Selected", they run in the same order their blocks appear in this
# file - not the order you tapped them in on screen. So if you want one
# exercise always done before another whenever both are picked (e.g. a
# basic hold before a harder progression of it), just make sure its
# block comes earlier in the file than the other one's. A few groups
# below are deliberately ordered this way already - look for a short
# comment right above those blocks.
#
# Note on this version: descriptions, setup, movement, and tip text below
# reflect a review by physical therapy professionals, building on an
# individually developed program. A few general osteoporosis exercise
# principles run throughout: progressive resistance and balance/functional
# training matter; movement should stay controlled, avoiding rapid,
# repetitive, loaded, or end-range spinal flexion or rotation; a hip hinge
# is the go-to way to bend while keeping the spine relatively stable;
# gentle, controlled, non-end-range trunk rotation is fine when it's
# comfortable; and "neutral" spine means a comfortable, controlled
# position, not a forced one - there's no need to deliberately flatten the
# low back against the floor unless an exercise specifically calls for it.
# Wording throughout avoids labeling positions as unconditionally "safe"
# or treating ordinary spinal movement as automatically dangerous.
#
# Resistance bands: progress to a stronger band once an exercise becomes
# comfortably manageable with good control. Band colors aren't specified
# here since color-to-resistance varies by manufacturer.

Slug: hip-abduction
Name: Hip Abduction - Standing
Category: hip
Equipment: band
Tags: band-optional:🎒
Sets: 4
Reps: 10
Seconds: 4
Rest: 6
Description: Strengthens the outer hip and glute muscles that help stabilize the pelvis during standing and walking. Do half your sets on each leg.
Setup: Loop the exercise band just below the knees. Stand beside a wall or sturdy chair and use it for balance as needed.
Movement: Keeping your working leg straight or slightly soft at the knee and your toes facing forward, move the leg out to the side against the band, pause briefly, then return with control.
Tip: Keep your toes facing forward throughout - turning them out lets the hip flexor assist, which works against isolating the glute. Keep your pelvis level and avoid leaning your torso to the side to create extra range.

Tip: Keep your toes facing forward throughout - turning them out lets the hip flexor assist, which works against isolating the glute. Keep the pelvis steady and do not use a large backward leg swing or an exaggerated low-back arch to get more range.

Slug: pnf-d2
Name: PNF D2 - Standing
Category: back-shoulder
Equipment: band
Sets: 4
Reps: 10
Seconds: 6
Rest: 6
Description: Trains the shoulder and upper-body muscles through a controlled diagonal reaching pattern.
Setup: Stand comfortably upright. Hold one end of the resistance band low at the side opposite the working arm and the other end in the working hand.
Movement: Sweep the working arm up and out along the diagonal pattern like pulling a sword from its sheath - start with your wrist neutral and let it rotate through the sweep, finishing with your wrist and palm facing forward once the arm is raised. Reverse the movement slowly to return.
Tip: Keep your wrist neutral through the turn and let the shoulder and arm do the work; avoid using trunk leaning or twisting to create extra range.

Slug: bridge
Name: Bridge
Category: hip
Equipment: bodyweight
Sets: 2
Reps: 10
Seconds: 5
Rest: 6
Description: Strengthens the glutes and hip extensors while training controlled pelvic stability.
Setup: Lie on your back with knees bent and feet flat on the floor, about hip-width apart.
Movement: Squeeze your glutes and lift your hips until your trunk and thighs form a comfortable straight line. Hold for 5 seconds, then lower with control.
Tip: Lift only as high as you can without an exaggerated low-back arch. The hold stays at 5 seconds - increase reps rather than hold time for more difficulty.
