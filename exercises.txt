# Rep Counter -- Exercise Data

# Edit this file to add, remove, or change exercises. No coding needed --
# just keep the "Field: value" shape below. Lines starting with # are
# comments and are ignored. Save the file and refresh the app to see your
# changes (the app also picks this up automatically the next time you're
# online, even after Add to Home Screen).
#
# One exercise per block, separated by a blank line. Fields can be in any
# order; you can leave optional fields blank.
#
# Required fields:
#   Slug          A short unique id: lowercase letters, numbers, and
#                 hyphens only, no spaces (e.g. hip-abduction). The app
#                 uses this to remember your sets/reps and "last done"
#                 history for this exercise -- once you've used an
#                 exercise, try not to change its Slug, or that history
#                 starts over. If you leave Slug blank, the app makes one
#                 up from Name, which is fine for a brand new exercise.
#   Name          The exercise name shown in the app.
#   Category      A short label to group exercises for filtering, e.g.
#                 hip, core, back-shoulder, arms, balance-legs. You can
#                 invent a new one just by typing it here -- a filter chip
#                 for it appears automatically.
#   Equipment     band, dumbbell, or bodyweight (also just a label -- a
#                 new one you invent gets its own filter chip too).
#   Sets / Reps / Seconds / Rest
#                 Starting numbers (Seconds = per rep, Rest = seconds
#                 between sets). These are just the defaults shown when
#                 you first open the exercise -- you can always change
#                 them per-exercise right in the app too.
#   Description   One sentence: what this exercise is for.
#   Setup         How to get into position.
#   Movement      How to do one rep.
#   Tip           A coaching cue or common mistake to avoid.
#
# Optional fields:
#   StartImage / FinishImage
#                 Filename of a photo in this same folder (e.g.
#                 IMG_0306.jpeg). Leave both blank to use a built-in
#                 line-drawing icon instead. Two common ways to fill these
#                 in:
#                   - One photo per position: put the start photo in
#                     StartImage and the finish photo in FinishImage -
#                     they're shown side by side.
#                   - One combined photo: if you already have a single
#                     photo showing both the start and finish position
#                     (e.g. a "before/after" side-by-side shot), just put
#                     its filename in StartImage and leave FinishImage
#                     blank - it's shown at full size instead of being
#                     cropped in half.

Reps: 10
Seconds: 3

Slug: pnf-d2
Name: PNF D2 - Standing
Category: back-shoulder
Equipment: band
Sets: 4
Reps: 10
Seconds: 5
Rest: 6
Description: A diagonal arm pattern that trains the shoulder and trunk to work together through a full range, mimicking reaching-and-rotating movements.
Setup: Hold one end of the resistance band low, at your side opposite your working arm. Hold the other end of the band with your working hand near the other hand.
Movement: Sweep your working arm in one smooth diagonal, up and out, finishing overhead and out to the side with your palm turning to face away from you. Keep wrist neutral. The whole movement is like removing a sword from a scabbard and pointing it upward. Reverse slowly to return.
Tip: Move through the whole diagonal smoothly - don’t just raise your arm straight up.
